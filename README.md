# workshop2
Второй проект в мастерской в рамках Яндекс Практикума

## Описание

Целью проекта является построение модели предсказания покупательной активности пользователей в интернет магазине. Из таблиц с данными о маркетинговых рассылках и покупках пользователей за период мы строим синтетические признаки и пыатемся предсказать совершит ли пользователь покупку в следующие три месяца. 

## Инструкция по использованию

Для запуска проекта понадобиться локально запустить проект и скачать данные, разместив их в относительной папке "../data/workShop2" (либо отредактировать файл notebook введя туда свой путь к файлам данных).
